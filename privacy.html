Política de Privacidade.

Última atualização: 24 de outubro de 2026

O Performance-G é uma aplicação de uso pessoal destinada à análise e ao planeamento desportivo.

Dados tratados

Mediante importação voluntária de ficheiros Garmin Connect, podem ser tratados datas, modalidades, tempos, distâncias, títulos de atividades, frequência cardíaca e potência, quando presentes. Também podem ser guardadas sessões planeadas. Não existe atualmente recolha automática de sono ou recuperação.

Finalidades

Os dados destinam-se exclusivamente à visualização do histórico, análise da evolução e organização dos treinos. Não são vendidos, utilizados para publicidade ou publicados neste site.

Armazenamento

O dashboard privado é executado no Streamlit Community Cloud e utiliza uma base de dados de trabalho no servidor. Quando autorizado, guarda uma cópia no Google Drive do proprietário. O GitHub aloja o código e este site informativo, não os dados pessoais de treino.

Google Drive API

A aplicação solicita o âmbito https://www.googleapis.com/auth/drive.file para criar, consultar e atualizar os ficheiros que gere no Drive. O acesso é concedido através do consentimento OAuth e pode ser revogado nas definições de segurança da conta Google. As credenciais são guardadas nas definições privadas do alojamento.

Serviços utilizados

Google Drive (armazenamento), Streamlit Community Cloud (alojamento da aplicação) e GitHub (código e site informativo) podem tratar informações de acordo com as respetivas políticas.

Conservação e eliminação

O proprietário pode eliminar os ficheiros armazenados no Google Drive e revogar o consentimento OAuth. Para eliminar também dados temporários alojados no servidor, deve assegurar a limpeza ou eliminação da instância Streamlit. A retenção técnica pelos fornecedores está sujeita às políticas de cada serviço.

Segurança e partilha

O dashboard está configurado para acesso restrito. Os dados não são partilhados publicamente nesta página. Nenhum mecanismo de segurança elimina todos os riscos.

Contacto

As questões relativas ao tratamento dos dados podem ser dirigidas ao endereço de suporte apresentado no ecrã de consentimento Google OAuth do Performance-G.

Atualizações

Esta política poderá ser revista à medida que forem adicionadas novas funcionalidades.
